# AI-Coding-Agent-

A minimal repository of Jupyter Notebook experiments for building and testing an AI coding agent.

## Contents

- **Jupyter Notebooks (`.ipynb`)**: Interactive notebooks containing code, notes, and outputs.

## Getting Started

### Prerequisites

- Python 3.10+ (recommended)
- JupyterLab or Jupyter Notebook

Install JupyterLab:

```bash
pip install jupyterlab
```

Launch:

```bash
jupyter lab
```

## Usage

1. Open the notebook(s) in Jupyter.
2. Run cells top-to-bottom.
3. Adjust parameters / prompts inside the notebook to experiment.

## Notes

- Notebooks may include large outputs; consider clearing outputs before committing.
- If you add Python dependencies, consider adding a `requirements.txt`.
